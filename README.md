# MailCloudSync — Облако Mail.ru на Маке

Маленькая программа для строки меню: держит выбранные папки Облака Mail.ru в обычной папке на вашем Маке.
Положили файл туда — он появился в Облаке. Изменили в Облаке — обновился на Маке.

Работает на Apple Silicon и Intel, macOS 11 и новее. В Dock значка нет — только синий значок с буквой «М» в строке меню.

## Важно: что нужно от Облака

У Облака Mail.ru нет официального API для программ — подключение идёт по протоколу **WebDAV**. Поэтому:

- WebDAV доступен **только на платных тарифах** Облака. На бесплатном тарифе подключиться не получится.
- Нужен не обычный пароль, а **пароль внешнего приложения** (создаётся в настройках безопасности Mail.ru, см. ниже).
- Через WebDAV нельзя создавать публичные ссылки и смотреть корзину Облака — этих функций здесь нет
  (в отличие от клиента для Яндекс Диска). Ссылки создавайте на cloud.mail.ru.

## Как собрать

Нужен Xcode или Command Line Tools. В Терминале:

```bash
cd ~/prog/MailCloudSync
./build.sh
```

Получится `MailCloudSync.app`. Перетащите её в «Программы» и запустите.

## Как настроить (один раз)

**1. Создайте пароль внешнего приложения**

1. Откройте Mail ID → «Безопасность» → «Пароли для внешних приложений» (кнопка «Как создать пароль…» в настройках программы откроет эту страницу).
2. Нажмите «Добавить», назовите, например, `WebDAV`, подтвердите паролем от аккаунта.
3. Скопируйте созданный пароль — повторно он не показывается.

**2. Настройте программу**

При первом запуске откроется окно настроек.

1. Введите почту (полностью, например `name@mail.ru`) и пароль внешнего приложения, нажмите «Подключить».
   Программа проверит доступ. Если Облако отказывает, значит WebDAV недоступен на вашем тарифе.
2. Сразу откроется окно «Что синхронизировать»: отметьте **«Всё Облако (корень)»** или только нужные папки. Нажмите «Готово».
3. «Выбрать…» — укажите папку на Маке, куда складывать файлы. Лучше создать отдельную, например `~/Облако Mail.ru`.
4. Нажмите «Сохранить и синхронизировать».

## Как пользоваться

Значок в строке меню показывает состояние: обычный — всё синхронизировано, **вращающиеся стрелки с процентами** — идёт синхронизация, значок с восклицательным знаком — ошибка, пауза — приостановлено.

По клику открывается меню:

- **Журнал синхронизации…** — полоса прогресса и лента событий (таймлайн): что скачано, загружено, удалено, где конфликт или ошибка.
- **Открыть папку на Маке** и **Открыть Облако Mail.ru в браузере**.
- **Синхронизировать сейчас**, **Приостановить / Возобновить**.
- **Настройки…** — сменить папку на Маке, выбрать другие папки Облака, интервал, запуск при входе в систему.

Изменения в папке на Маке отправляются в Облако **сразу** (в пределах пары секунд). Облако проверяется раз в несколько минут (по умолчанию 5).
Если пропала сеть, программа ждёт и продолжает сама, когда связь вернётся.

## Что нужно знать

- **Структура одинаковая.** Папка `Документы` из Облака окажется как `<ваша папка>/Документы`.
- **Что удаляется в Облаке.** Только то, что вы сами удалили на Маке. Если удалить что-то в Облаке, на Маке оно уйдёт в Корзину.
  Попадает ли удалённое в корзину Облака, зависит от сервера — проверьте на своём аккаунте, прежде чем доверять важное.
- **Убрали папку из синхронизации** (сняли галочку) — её копия на Маке удаляется (в Корзину), а **в Облаке ничего не меняется**.
- Если разом нужно удалить очень много файлов, программа остановится и спросит подтверждение в меню.
- **Конфликты.** Если файл изменили и тут, и там, на Маке останется копия «имя (конфликт дата).расширение», а основной файл станет версией из Облака.
- **Как определяются изменения.** WebDAV не сообщает контрольные суммы, поэтому изменения определяются по размеру и времени изменения файла.
  При первой синхронизации файлы с одинаковым размером сравниваются по содержимому (для этого скачиваются).
- Скрытые файлы (начинаются с точки), временные файлы Office (`~$…`) и ссылки-алиасы не синхронизируются.
- Пароль хранится в связке ключей macOS. При пересборке с ad-hoc подписью система может заново спросить доступ — нажмите «Всегда разрешать».

## Из чего состоит

```
Sources/main.swift             запуск и меню
Sources/StatusController.swift значок и меню в строке меню
Sources/SettingsView.swift     окно настроек и окно выбора папок Облака
Sources/SyncEngine.swift       сама синхронизация
Sources/WebDAV.swift           клиент WebDAV
Sources/FolderWatcher.swift    слежение за папкой на Маке
Sources/ActivityLog.swift      журнал событий и прогресс
Sources/ActivityView.swift     окно «Журнал синхронизации» (таймлайн)
Sources/Settings.swift         настройки и связка ключей
Tools/make_icon.swift          рисует иконку при сборке
```
